# SecurityScan-Agent

An AI-powered security vulnerability scanner with a cyberpunk-inspired dark theme, built with **MiMo V2.5**.

## Features

- Simulated security scanning with real-time progress
- Vulnerability list with severity levels (Critical, High, Medium, Low)
- Cyber dark theme with neon accents
- Scan progress visualization
- Detailed vulnerability reports
- Network port scan results
- CVE detection simulation

## Tech Stack

- Vanilla HTML5, CSS3, JavaScript (ES6+)
- CSS animations for scanning effects
- Zero dependencies

## Getting Started

1. Open `index.html` in a modern web browser
2. Click "Start Scan" to begin the security scan
3. Monitor vulnerability findings in real-time
4. Click on individual findings for detailed reports

## Vulnerability Severity Levels

- **Critical** (red): Remote code execution, SQL injection
- **High** (orange): Privilege escalation, XSS
- **Medium** (yellow): Misconfigurations, weak cryptography
- **Low** (blue): Information disclosure, outdated software

Built with MiMo V2.5 AI assistance.
